# Notebooks

This directory contains the project's numbered mathematical investigations.

Planned sequence:

1. `01_problem_formulation.ipynb`
2. `02_deterministic_optimization.ipynb`
3. `03_stochastic_optimization.ipynb`
4. `04_robust_optimization.ipynb`
5. `05_strategy_comparison.ipynb`

Notebooks should explain the reasoning behind the model, not merely execute code.

Where practical, each investigation should include:

- Question or objective
- Mathematical background
- Assumptions
- Derivation
- Predictions before computation
- Implementation
- Verification
- Visualization
- Interpretation
- Limitations
- Conclusions

Reusable implementation code should eventually move into `src/` rather than being duplicated across notebooks.
